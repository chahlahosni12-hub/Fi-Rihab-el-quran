============================================================
 مشروع: في رحاب القرآن (منصة تحفيظ القرآن الكريم)
============================================================

وصف المشروع:
منصة وب (Web App) متكاملة ومخصصة لمتابعة حفظ القرآن الكريم وتسميعه. 
تربط المنصة بين المحفّظ (المدير) وبين الطلبة، بحيث يمكن للطالب تسجيل صوته 
أثناء التسميع وإرساله للمعلم، ومتابعة الواجبات، بينما يستطيع المعلم 
إدارة الحسابات، الاستماع للتسجيلات، وتقييم الطلبة لحظياً عبر السحاب.

------------------------------------------------------------
 التقنيات المستخدمة (Technologies):
------------------------------------------------------------
- HTML5 / CSS3: لتصميم الواجهات وتجربة المستخدم.
- JavaScript (ES6+): منطق التشغيل والتفاعل مع الواجهة.
- Firebase v10:
    * Firebase Authentication: لإدارة تسجيل دخول المعلم والطلبة بأمان.
    * Cloud Firestore: لتخزين بيانات الطلبة، السجلات، والواجبات.
    * Base64 / Audio Storage: لتخزين وحفظ التسجيلات الصوتية للتسميع.
- Service Worker (sw.js): لدعم العمل جزئياً والتخزين المؤقت (Cache).

------------------------------------------------------------
 هيكل المشروع (Project Files):
------------------------------------------------------------
- admin-recitations.html : الواجهة الرئيسية للوحة التحكم والتسميع.
- app.js                 : الكود البرمجي الأساسي ومنطق ربط Firebase والتسجيل الصوتي.
- style.css              : ملف التنسيقات والتصميم المرئي.
- sw.js                  : ملف الـ Service Worker لتخزين الملفات وتسريع التحميل.

------------------------------------------------------------
 طريقة التشغيل والإعداد (Setup Instructions):
------------------------------------------------------------
1. قم بإنشاء مشروع جديد على لوحة تحكم Firebase (https://console.firebase.google.com).
2. فعّل خدمة Authentication (البريد الإلكتروني وكلمة المرور).
3. فعّل قاعدة بيانات Firestore Database.
4. انسخ بيانات مشروعك (firebaseConfig) وضعها في ملف `app.js`.
5. حدد بريد المعلم (Admin Email) في متغير `ADMIN_EMAIL` داخل ملف `app.js`.
6. افتح المشروع عبر خادم محلي (مثل Live Server في VS Code) أو ارفعه 
   على استضافة تدعم HTTPS لضمان عمل الميكروفون وتسجيل الصوت بشكل سليم.

 حقوق الطبع والنشر والتطوير:
