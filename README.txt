في رحاب القرآن — حزمة PWA أولية
=================================

هذه الحزمة تضيف ملفات PWA حتى يمكن تثبيت الموقع على الشاشة الرئيسية من Safari عند نشره عبر HTTPS.

الملفات:
- index.html: الواجهة التجريبية.
- manifest.webmanifest: تعريف التطبيق واسمه ومظهره.
- sw.js: تخزين بعض ملفات الواجهة للاستخدام عند ضعف الاتصال.
- icon.svg: أيقونة أولية.

تجربة على iPhone:
1. انشر الملفات على استضافة HTTPS (مثال GitHub Pages أو Netlify).
2. افتح رابط الموقع في Safari.
3. اضغط مشاركة، ثم "إضافة إلى الشاشة الرئيسية"، ثم فعّل "فتح كتطبيق ويب" إن ظهر الخيار.

تنبيه أمان:
- هذه نسخة تجريبية محلية وليست منصة متعددة المستخدمين.
- لا تستخدم بيانات حقيقية للطلبة قبل إضافة مصادقة وقاعدة بيانات بصلاحيات وصول آمنة.
- لا ترفع أي مفاتيح سرية أو كلمات مرور إلى مستودع عام.
- ذاكرة العمل دون اتصال لا تجعل البيانات المحلية آمنة أو متزامنة.

قبل النشر على المتاجر:
- إضافة قاعدة بيانات ومصادقة حقيقية.
- سياسة خصوصية وحذف الحساب عند الحاجة.
- حسابات اختبار ومحتوى كامل ومراجعة تجربة المستخدم.
- بناء تطبيق أصلي/مغلف واختباره على أجهزة فعلية.
